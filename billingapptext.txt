# Tea Shop Management, QR Ordering, Customer Credit & Financial Analytics System

## 1. Project Overview

I want to build a real-world full-stack **Tea Shop Management and Customer Ordering System**.

The application should allow customers to scan a QR code at the tea shop, open the shop's digital menu on their mobile phone, register/login using their mobile number, select products, place orders, make payments or purchase on credit, and view their order history.

The shop owner/admin should have a separate dashboard to manage:

* Customers
* Menu items
* Categories
* Orders
* Payments
* Customer credit
* Credit limits
* Pending amounts
* Shop expenses
* Shop income
* Sales reports
* Customer reports
* Product sales reports
* Financial reports
* Basic data analytics
* Basic AI/ML features

The application should be designed as a real-world production-style application.

# 12. Important Order Concept

When an order is created, store the product's price at that moment.

For example:

Today:

```text
Tea = ₹15
```

Customer buys 2:

```text
2 × ₹15 = ₹30
```

Tomorrow admin changes Tea price to:

```text
₹20
```

The old order must still show:

```text
2 × ₹15 = ₹30
```

Therefore, `order_items.unit_price` must store the price at the time of purchase.

# 15. Credit Limit Validation

Before allowing a customer to purchase on credit:

```text
current_balance + order_amount <= credit_limit
```

Example:

```text
Credit Limit = ₹5,000

Current Balance = ₹4,700

New Order = ₹200

₹4,700 + ₹200 = ₹4,900

Allowed
```

But:

```text
Credit Limit = ₹5,000

Current Balance = ₹4,900

New Order = ₹200

₹4,900 + ₹200 = ₹5,100

REJECT
```

Return a clear error:

```text
Credit limit exceeded.

Available credit: ₹100
Order amount: ₹200
```

# 42. Transaction Safety

Order creation and credit updates must be handled safely.

For a credit order:

```text
1. Validate customer
2. Validate products
3. Calculate total
4. Check credit account
5. Check credit limit
6. Create order
7. Create order items
8. Update credit balance
9. Create credit transaction
10. Commit transaction
```

If something fails, the database transaction should roll back.

Do not allow situations where:

```text
Order created
BUT
Credit balance not updated
```
